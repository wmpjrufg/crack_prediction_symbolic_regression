# Virtual environment  
`python -m venv env`  

# Activate
Linux: `source env/bin/activate` 
Windows: `env\Scripts\activate`  

# Install requirements
`pip install -r requirements.txt`

# Deactivate  
`deactivate`  

# Reactivate
Linux: `source env/bin/activate` 
Windows: `env\Scripts\activate`
